## 公共上下文

| 项 | 值 |
|----|-----|
| 起始页面 | 项目详情页 → 组织架构 Tab → 已选中某公司 |
| 用户角色 | PM（项目经理） |
| 浏览器 | Chromium（Playwright） |
| 视口尺寸 | 1280 x 720 |
| 语言 | 中文（zh-CN） |

### 测试数据准备说明

E2E 测试通过浏览器操作 UI，前置条件中的"已有数据"指**页面上可见的数据状态**：

| 数据标识 | 页面可见状态 |
|---------|------------|
| 公司已选中 | 组织架构 Tab 中某公司卡片高亮，右侧显示该公司的部门树形列表 |
| 有多级部门的公司 | 树形列表中显示 ≥ 2 级嵌套节点（如"研发部→前端组→React 小组"），可展开/折叠 |
| 有角色的部门 | 某树节点旁显示"N 个已挂载角色"徽章文本 |

## 正常流程

### TC-E2E-M1-07-001 查看部门列表 — 树形渲染 + 层级缩进 + 统计徽章

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-07-001 |
| **用例名称** | 部门树渲染 — 进入组织架构 Tab 选中公司后，树形组件正确展示层级关系、缩进、统计信息 |
| **对应AC** | §4.7.3 步骤 1~3, B-M1-41, UI 元素 #5~9 |
| **优先级** | P0 |
| **前置条件** | 已在项目详情页组织架构 Tab；选中 `company-a`（含 dept-root → dept-child → dept-grandchild 三级结构） |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 观察部门视图区域 | 显示「新建部门」按钮 + 搜索框 + 展开/折叠全部按钮 + 树形列表 |
| 2 | 观察顶级节点（dept-root） | display_name 可见；无左侧缩进（或最小缩进）；level=1 视觉表现正确 |
| 3 | 点击 dept-root 的展开按钮 | 子节点 dept-child 出现，有比父节点更深的缩进；dept-root 的 children_count 徽章与实际子节点数一致 |
| 4 | 展开 dept-child | 孙节点 dept-grandchild 出现，缩进更深（三级）；role_count / children_count 徽章均可见 |
| 5 | 观察另一个顶级节点 dept-sibling | 与 dept-root 同级（相同缩进深度）；独立于 dept-root 的子树 |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 树形结构 | 使用树形组件（非扁平列表），支持展开/折叠交互 |
| 层级缩进 | 每深一层缩进增加，视觉上能区分 1/2/3 级 |
| 统计徽章 | role_count 和 children_count 以徽章文本形式展示在节点旁 |
| 排序 | 同级节点按 created_at DESC 排列（B-M1-41） |
| 工具栏 | 「新建部门」+ 搜索框 + 展开/折叠全部按钮均可见且可用 |

| **用例名称** | 循环引用 — 编辑部门时将 parent_id 改为其子节点，检测到环路后 Toast 提示 + 保存失败 |
| **对应AC** | B-M1-52b, §4.7.4.7 CIRCULAR_REFERENCE |

| 步骤 | 操作 | 页面预期 |
|------|------|---------|

| 2 | 在 parent_id 下拉中选择 dept-child（dept-root 的子节点） | 下拉选项应包含 dept-child（UI 层可能过滤掉后代节点——以实现为准） |

| 断言项 | 预期 |

| 错误提示 | 用户友好中文，解释"循环引用"概念 |
| 对话框状态 | 保持打开，允许用户重新选择合法的 parent_id |
| 数据完整性 | dept-root 的 parent_id 未被修改（B-M1-52b 后置验证） |
