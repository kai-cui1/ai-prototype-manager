### 🆕 视觉还原验证范围（§10 强制要求）

|---------|---------------------------|-------------|

### 测试数据准备说明

E2E 测试通过浏览器操作 UI，前置条件中的"已有数据"指**页面上可见的数据状态**：

| 数据标识 | 页面可见状态 |
|---------|------------|
| 外部实体子 Tab 已加载 | 组织架构 Tab 下切换到「外部实体」区域，显示外部实体卡片列表 |
| 有不同类型的外部实体 | 卡片列表中含 type=system / organization 等不同类型的实体，各显示对应中文 Badge |

### TC-E2E-M1-09-001 查看外部实体列表 — 卡片渲染 + 类型 Badge + 操作按钮

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-09-001 |
| **用例名称** | 外部实体列表渲染 — 进入组织架构 Tab→「外部实体」子区域后，卡片列表正确展示名称、类型 Badge、描述、操作按钮 |
| **对应AC** | AC-M1-22, B-M1-71, UI 元素 #3~7 |
| **优先级** | P0 |
| **前置条件** | 已在项目详情页组织架构 Tab；切换到「外部实体」子 Tab；proj-active 下有 ≥ 1 个外部实体 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 在组织架构 Tab 中点击「外部实体」子 Tab | 子区域切换；加载外部实体卡片列表；工具栏显示「新建外部实体」+ 搜索框 |
| 2 | 观察卡片列表 | 每张卡片包含：display_name、type Badge（如"系统"/"组织机构"/"个人角色"/"接口"）、description（截断）、编辑/删除按钮 |
| 3 | 观察 type=system 的卡片 | type Badge 显示"系统"（中文映射） |
| 4 | 观察 type=organization 的卡片 | type Badge 显示"组织机构" |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 子 Tab 位置 | 「外部实体」为组织架构 Tab 下的子区域/子 Tab（与公司部门并列） |
| type Badge | 显示 type 枚举值的中文映射（非原始英文值） |
| 工具栏完整性 | 新建 + 搜索均可见且可用 |
| 排序 | 按 created_at DESC 排列（B-M1-71） |

### TC-E2E-M1-09-002 创建外部实体 — 完整流程（弹窗→含 type 选择→提交→新卡片出现）

| 字段 | 内容 |

| **用例ID** | TC-E2E-M1-09-002 |
| **用例名称** | 新建外部实体 — 点击新建 → 填写表单（含 type 下拉选择）→ 提交 → 列表新增卡片 |
| **对应AC** | §4.9.3 新建主流程步骤 1~3, B-M1-12（Toast 提示） |
| **优先级** | P0 |
| **前置条件** | 已在「外部实体」子区域 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 点击「新建外部实体」按钮 | 弹出新建对话框；含 name / display_name / type（下拉选择）/ description 输入框 |
| 2 | 在 type 下拉中选择`系统`（或 `organization` / `person` / `interface`） | 下拉选项包含 4 种合法枚举值及其中文标签 |
| 3 | 填写 name=`new-ee-e2e`，display_name=`新外部实体-E2E`，description=`测试描述` | 各字段正常接受输入 |
| 4 | 点击「提交」按钮 | 按钮 loading 态；请求发送 |
| 5 | 等待响应 | 对话框关闭；Toast："外部实体「新外部实体-E2E」创建成功"；列表新增一张卡片 |
| 6 | 观察新卡片的 type Badge | 显示所选类型的中文映射（如选了 system 则显示"系统"） |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 对话框字段 | 含 name / display_name / type（枚举下拉）/ description |
| type 下拉内容 | 包含全部合法枚举值（system/organization/person/interface）+ 中文标签 |
| Toast 文案 | 包含"创建成功"和 display_name |
| 新卡片 type Badge | 与所选 type 对应的中文映射一致 |
| loading 态 | 提交按钮有 spinner + 禁用（UI-M1-02） |
