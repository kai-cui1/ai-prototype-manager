### 测试数据准备说明

E2E 测试通过浏览器操作 UI，前置条件中的"已有数据"指**页面上可见的数据状态**：

| 数据标识 | 页面可见状态 |
|---------|------------|
| 活跃项目详情 | 详情页显示一个 status=active 的项目，基本信息卡可见 |
| 已归档项目详情 | 详情页显示一个 status=archived 的项目，无编辑/归档按钮 |
| 有同名项目存在 | DB 中存在另一个 name=`another-proj` 的活跃项目（用于唯一性冲突测试） |

## 正常流程

### TC-E2E-M1-04-001 进入编辑模式 — 点击字段切换为可编辑状态

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-04-001 |
| **用例名称** | 进入编辑 — 点击详情页字段，切换为行内编辑态（输入框 + 保存/取消按钮） |
| **对应AC** | §4.4.3 步骤 1~2 |
| **优先级** | P0 |
| **前置条件** | 已在活跃项目详情页；基本信息卡显示只读字段值 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 点击 `name` 字段的文本区域或编辑图标 | 该字段从只读文本变为输入框；输入框预填充当前值 `"editable-proj"`；周围出现「保存」（主要样式）和「取消」（次要样式）按钮 |
| 2 | 观察 display_name 和 description 字段 | 保持只读展示态（未点击的字段不自动变为可编辑） |
| 3 | 观察 created_at / updated_at / version 字段 | 保持只读且不可点击（这些是系统字段） |
| 4 | 在 name 输入框中修改值为 `modified-name` | 输入框实时显示新值 |
| 5 | 按 Esc 键 | 退出编辑模式；name 恢复为原值 `"editable-proj"`；保存/取消按钮消失 |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 编辑态触发方式 | 点击字段即可进入编辑（无需额外"编辑"按钮——但顶部栏的"编辑"按钮也可触发全局编辑态） |
| 预填充值 | 输入框显示当前字段的原值 |
| 只读字段不变 | created_at / updated_at / version 在编辑态下仍为只读 |
| Esc 取消 | 按 Esc 等同于点击「取消」，恢复原值 |

### TC-E2E-M1-04-002 编辑并保存成功 — 全字段修改 + Toast + 版本号刷新

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-04-002 |
| **用例名称** | 保存成功 — 修改 name + display_name + description 后点击保存，字段恢复只读并显示新值，version+1 |
| **对应AC** | §4.4.3 步骤 3~5 |
| **优先级** | P0 |
| **前置条件** | 已在活跃项目详情页（version 显示为 v1）；DB 中无 name=`fully-edited-proj` 的其他项目 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 点击顶部栏「编辑」按钮或点击任一字段 | 进入行内编辑模式：所有可编辑字段（name / display_name / description）变为输入框/文本域；底部出现「保存」「取消」按钮 |
| 2 | 将 name 改为 `fully-edited-proj` | 输入框显示新值；无格式错误提示 |
| 3 | 将 display_name 改为 `完整编辑后的项目名` | 同上 |
| 4 | 将 description 改为 `这是编辑后的描述内容` | 文本域显示新值 |
| 5 | 点击「保存」按钮 | 按钮 loading 态（spinner + 禁用）；编辑态保持 |
| 6 | 等待请求完成 | loading 结束；退出编辑模式；所有字段恢复为只读展示；显示新值；出现 Toast："项目信息已更新"；version 从 `v1` 变为 `v2`；updated_at 时间刷新为当前时间 |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 退出编辑态 | 所有字段回到只读展示，无输入框和保存/取消按钮 |
| name 新值 | 显示 `"fully-edited-proj"` |
| display_name 新值 | 显示 `"完整编辑后的项目名"` |
| description 新值 | 显示 `"这是编辑后的描述内容"` |
| version 递增 | 从 `v1` 变为 `v2` |
| updated_at 刷新 | 时间更新为最近时刻（非原值） |
| Toast 提示 | 出现且文案包含"更新"或"保存成功" |
| 创建时间不变 | created_at 仍为原值 |

### TC-E2E-M1-04-003 取消编辑 — 快照还原（Esc + 取消按钮两种方式）

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-04-003 |
| **用例名称** | 取消编辑 — 修改字段后点击取消或按 Esc，所有字段还原到进入编辑时的原始值 |
| **对应AC** | §4.4.6 AI 提示（快照还原：取消时还原到 onEditStart 时的快照） |
| **优先级** | P0 |
| **前置条件** | 已在活跃项目详情页（原始值：name=`editable-proj`, display_name=`可编辑项目`, desc=null, version=v1） |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 进入编辑模式 | 字段变为可编辑，预填充原始值 |
| 2 | 修改 name 为 `will-be-discarded` | 输入框显示新值 |
| 3 | 修改 display_name 为 `将被丢弃` | 同上 |
| 4 | 在 description 中输入 `这段也会丢弃` | 同上 |
| 5 | 点击「取消」按钮 | 立即退出编辑模式；三个字段全部还原为原始值：name=`editable-proj`, display_name=`可编辑项目`, description=— 或空 |
| 6 | （变体）再次进入编辑，修改所有字段后按 Esc 键 | 效果同上：还原到原始值 |
| 7 | 观察版本号 | 仍为 `v1`（取消不触发 API，version 不变） |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 取消后字段值 | 完全等于进入编辑前的原始值（不是"上一次保存的值"，而是本次进入时的快照） |
| 取消后 version | 不变（未递增） |
| 取消后 updated_at | 不变（未刷新） |
| 两种取消一致性 | 「取消」按钮和 Esc 键效果完全一致 |

| **用例名称** | Enter 快捷键 — 在 name 或 display_name 单行输入框中按 Enter 等同于点击保存 |
| **对应AC** | §4.4.3 快捷操作：Enter = 保存（仅单行输入框） |
| **优先级** | P1 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |

| 修正后可重提交 | 更换 name 后再次保存能成功 |
| version 变化 | 最终成功时 version 递增（失败时不递增） |

## 异常交互

### TC-E2E-M1-04-008 乐观锁冲突 — 弹窗提示 + 强制刷新页面

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-04-008 |
| **用例名称** | 版本冲突 — 编辑期间他人已修改同一项目，提交时返回 VERSION_CONFLICT |
| **对应AC** | G-M1-07, §4.4.4.7 VERSION_CONFLICT, §4.4.3 步骤 7 |
| **优先级** | P0 |
| **前置条件** | 已进入编辑模式；通过测试手段模拟 version 不匹配（如在另一标签页先执行了一次编辑使 version 变为 2，当前页面仍持 version=1） |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 修改任意字段值（如 display_name 改为 `冲突测试`） | 编辑态正常 |
| 2 | 点击「保存」按钮 | 按钮 loading → 返回 409 VERSION_CONFLICT |
| 3 | 观察前端处理 | 弹出 Dialog/Alert 提示："数据已被其他人修改，请刷新页面重试"；关闭编辑态 |
| 4 | 点击弹窗中的确认/刷新按钮 | 页面重新加载最新数据；字段显示他人修改后的最新值（非本用户刚输入的值）；version 显示为最新值 |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 冲突提示类型 | 弹窗（Dialog/Alert），非字段级错误提示（与 name 冲突的处理方式不同） |
| 提示文案 | 包含"已被其他人修改""刷新""重试"语义 |
| 关闭编辑态 | 冲突后强制退出编辑模式（不允许保持在编辑态） |
| 数据刷新 | 刷新后显示服务端最新数据，而非用户的过期修改 |
