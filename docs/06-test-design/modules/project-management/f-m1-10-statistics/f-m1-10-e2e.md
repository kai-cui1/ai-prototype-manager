# 统计摘要 — E2E 测试用例

> 功能点: **F-M1-10** | 优先级: **P1**
> 对应 PRD: `docs/03-prd/modules/project-management/project-management-prd-2.md` §4.10

---

## 公共上下文

| 项 | 值 |
|----|-----|
| 起始页面 | 项目列表页 / 项目详情页概要区 |
| 用户角色 | PM（项目经理） |
| 浏览器 | Chromium（Playwright） |
| 视口尺寸 | 1280 x 720 |
| 语言 | 中文（zh-CN） |

### 测试数据准备说明

E2E 测试通过浏览器操作 UI，前置条件中的"已有数据"指**页面上可见的数据状态**：

| 数据标识 | 页面可见状态 |
|---------|------------|
| 有数据的项目行 | 列表页某项目行右侧显示统计数字 Badge（如"3 实体 / 1 流程 / 5 组织"） |
| 空数据的项目行 | 列表页某项目行显示全 0 统计（灰色 "0" 徽章） |
| 详情页概要区 | 项目详情页显示模块摘要卡片网格（2x2 或 3x2 布局），每张卡片含计数 + 入口链接 |

## 正常流程

### TC-E2E-M1-10-001 项目列表页内嵌摘要 — 行内数字徽章展示

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-10-001 |
| **用例名称** | 列表页统计 — 每个项目行右侧展示关键统计数字（使用 Badge/Micro-charts 样式），无需额外请求 |
| **对应AC** | AC-M1-23, §4.10.2 位置1（列表页行内摘要）, B-M1-88（避免 N+1 查询）, AC-M1-U08（Badge 样式 + 0 值灰色显示） |
| **优先级** | P0 |
| **前置条件** | 已在项目列表页；列表中有 `proj-with-data`（有子数据）和 `proj-empty`（无子数据） |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 观察项目列表 | 每行包含：项目名称 + 状态 Badge + **行内统计区域** + 更新时间 |
| 2 | 观察 proj-with-data 的行内统计 | 显示类似"📊 N 实体 / M 流程 / O 组织"的 Badge 组合或 Micro-charts；各数字 > 0 |
| 3 | 观察 proj-empty 的行内统计 | 各统计项均显示为灰色 "0"（**不隐藏该项**） |
| 4 | 验证无额外请求 | 列表渲染期间不应出现额外的统计 API 调用（数据已内嵌在列表响应中）（可通过 Playwright network 监控验证） |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 内嵌数据 | 统计数字来自列表响应的内嵌字段，非额外请求（B-M1-88） |
| 样式 | 使用 Badge 或 Micro-charts 样式（AC-M1-U08），非纯文本 |
| 0 值显示 | 空数据项目的统计显示为灰色 "0"，**不隐藏**该统计项（§4.10.6） |
| 数字准确性 | proj-with-data 的各数字与实际子数据量一致 |

### TC-E2E-M1-10-002 项目详情页概要区 — 摘要卡片网格

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-10-002 |
| **用例名称** | 详情页摘要 — 概要区以卡片网格布局（2x2 或 3x2）展示 6 类对象计数，每张卡片含数字 + 入口链接 |
| **对应AC** | §4.10.2 位置2（详情页概要区）, 与 F-M1-03 的 Summary API 重叠 |
| **优先级** | P0 |
| **前置条件** | 已在项目详情页；`proj-with-data` 的详情页已加载完成 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 进入 `proj-with-data` 的详情页 | 页面加载；并行请求详情 + 摘要（F-M1-03 AC-M1-08）；概要区渲染 |
| 2 | 观察概要区布局 | 卡片网格布局（2x2 或 3x2）；每张卡片代表一类对象 |
| 3 | 观察各卡片内容 | 每张卡片含：图标/标题 + **大号数字**（计数）+ 可点击入口（跳转到对应 Tab） |
| 4 | 验证 6 类对象全覆盖 | 卡片涵盖：领域实体 / 业务流程 / 公司 / 部门 / 角色 / 外部实体 |
| 5 | 点击某卡片的入口 | 导航到对应的 Tab 或视图（如点击"部门"→组织架构 Tab） |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 并行请求 | 详情 + 摘要 API 并行请求（AC-M1-08），总耗时 = max(两者) |
| 6 类全覆盖 | 所有 6 种统计维度均有独立卡片 |
| 可交互性 | 卡片可点击跳转到对应功能区域 |
| 数字准确性 | 各卡片数字与实际数据量一致 |

### TC-E2E-M1-10-003 空数据项目详情 — 全 0 摘要卡片正常展示

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-10-003 |
| **用例名称** | 零值详情摘要 — 无任何子数据的项目的详情页概要区，所有卡片显示 "0" 且不隐藏 |
| **对应AC** | §4.10.3 步骤 4（0 值不隐藏）, §4.10.6, AC-M1-U08 |
| **优先级** | P0 |
| **前置条件** | 已在 `proj-empty` 的详情页 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 观察 `proj-empty` 的概要区 | 6 张摘要卡片全部存在 |
| 2 | 观察每张卡片的数字 | 均显示为 "0"；样式为灰色（区别于有数据的正常色） |
| 3 | 验证卡片未被隐藏 | 无任何卡片因值为 0 而消失或折叠 |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 0 值可见 | 所有 6 个统计维度均显示（§4.10.6："0 值不隐藏"） |
| 灰色区分 | 0 值使用灰色样式（AC-M1-U08），与有数据的正常颜色可区分 |
| 卡片完整性 | 即使全部为 0，6 张卡片仍完整展示 |

## 异常交互

### TC-E2E-M1-10-004 归档项目统计 — 列表页和详情页均正常展示

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-10-004 |
| **用例名称** | 归档项目统计 — 归档项目的列表行内摘要和详情页摘要均正常显示统计数据 |
| **对应AC** | B-M1-90（归档项目统计数据仍正常计算和展示） |
| **优先级** | P0 |
| **前置条件** | 已在归档项目 `proj-archived` 的列表页或详情页 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | （变体 A）在列表页观察 proj-archived 的行 | 行内统计区域正常显示数字（非空白/非错误），反映该归档项目下的实际子数据量 |
| 2 | （变体 B）进入 proj-archived 的详情页观察概要区 | 摘要卡片正常显示各统计数字 |
| 3 | 验证归档视觉区分 | 项目本身有灰色「已归档」Badge（UI-M1-07），但**统计数据不受影响** |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 列表统计正常 | 归档项目行的统计数字正确（B-M1-90：统计不受 status 过滤） |
| 详情统计正常 | 概要区卡片数字正确 |
| 归档标识独立 | 「已归档」Badge 与统计数字是两个独立的 UI 元素 |

### TC-E2E-M1-10-005 统计查询超时 — 降级显示占位符

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-10-005 |
| **用例名称** | 超时降级 — 摘要 API 超时时，详情页显示"—"占位而非白屏/错误边界 |
| **对应AC** | §4.10.4.7 #1（TIMEOUT → 显示"--"占位，不阻塞列表渲染） |
| **优先级** | P1 |
| **前置条件** | 通过 Playwright 模拟 Summary API 超时（route mock 返回 504 或延迟响应） |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 进入某项目详情页 | 正常发起详情 + 摘要并行请求 |
| 2 | 模拟 Summary API 超时（返回 504 或延迟 > 5s） | 摘要区域显示降级态 |
| 3 | 观察降态表现 | 摘要卡片区域的数字位置显示"—"（横线/破折号）或 loading skeleton；**页面其余部分正常**（基本信息卡等不受影响） |
| 4 | 观察列表页行为 | 若列表内嵌统计也超时 → 行内统计显示"—"或降级 Badge；**列表本身仍渲染**（不阻塞） |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 不阻塞渲染 | 超时不导致整个页面白屏或 Error Boundary |
| 降级占位 | 显示"--"或 skeleton，用户可知"数据正在加载中" |
| 重试机制 | 可能自动重试或提供手动刷新入口（以实现为准） |
