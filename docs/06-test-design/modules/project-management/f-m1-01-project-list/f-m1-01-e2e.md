### 测试数据准备说明

E2E 测试通过浏览器操作 UI，前置条件中的"已有数据"指**页面上可见的数据状态**：

| 数据标识 | 页面可见状态 |
|---------|------------|
| 有项目列表 | 列表区域显示 ≥ 1 行项目数据 |
| 有活跃+归档混合 | 列表中同时存在活跃和已归档项目 |
| 空列表 | 列表区域显示空状态占位 |

### TC-E2E-M1-01-001 进入系统查看项目列表

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-01-001 |
| **用例名称** | 进入项目列表页 — 渲染完整列表含搜索栏、筛选器、表格、分页 |
| **对应AC** | AC-M1-01 |
| **优先级** | P0 |
| **前置条件** | 浏览器打开项目列表页；PM 用户已登录；DB 中存在 3 个活跃项目 + 1 个归档项目 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 等待页面加载完成（Skeleton 消失） | 页面顶部显示搜索框、状态筛选 Tag 组（全部/活跃/已归档）、新建按钮 |
| 2 | 观察数据表格区域 | 表格显示表头行（名称 / 编程标识符 / 状态 / 版本 / 更新时间），下方有数据行 |
| 3 | 观察数据行数量 | 显示 4 行数据（3 活跃 + 1 归档，默认"全部"视图） |
| 4 | 观察第一行数据 | 第一行显示最新更新的项目信息：display_name、name 小字标注、绿色"活跃"Badge、版本号、更新时间 |
| 5 | 观察分页控件 | 底部显示分页器，当前页码为 1，每页条数为 20 |
| 6 | 观察新建按钮位置 | 页面顶部操作栏右侧有主样式的「新建项目」按钮 |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| URL | 等于 `/projects`（或等效路径） |
| 搜索框 | 可见且可输入，placeholder 含"搜索"相关提示文字，**宽度 ≈ 240px** |
| 状态筛选器 | 可见，默认选中"全部"Tag；**选中态 Badge 背景为主色(#08979c)+白字** |
| 新建按钮 | 可见，非禁用态；**背景=主色、圆角=6px、高度=36px** |
| 数据表格 | 至少 1 行数据可见；**容器圆角=8px、边框=#f0f0f0** |
| 表格头行 | **背景=#fafafa、字号=13px、font-weight=600、文字居中** |
| **🆕 活跃项目状态 Badge** | **背景≈#e6fffb(teal浅)、文字≈#13c2c2(teal)、有边框**（非纯文字无底色） |
| **🆕 归档项目状态 Badge** | **背景≈#fff7e6(橙浅)、文字≈#fa8c16(橙)、有边框**（区别于活跃态） |

| **🆕 操作列"归档"链接** | **颜色=红色#ff4d4f** |
| 分页器 | 可见，显示总条数 ≥ 1；**页码按钮圆角=6px、当前页=主色填充** |
| **🆕 Sidebar（亮色模式）** | **背景为白色(非黑色)、文字为深灰(非白色)** |

### TC-E2E-M1-01-002 按名称搜索项目

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-01-002 |
| **用例名称** | 搜索 — 输入关键词后防抖过滤列表 |
| **对应AC** | AC-M1-02 |
| **优先级** | P0 |
| **前置条件** | 已在项目列表页，列表显示多个项目（含 name 包含 `alpha` 和不含 `alpha` 的项目） |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 点击搜索框使其获得焦点 | 搜索框获得焦点，光标闪烁 |
| 2 | 在搜索框中输入 `alpha` | 输入框显示 `alpha`，列表暂不变化（等待防抖） |
| 3 | 等待 300ms+ 防抖延迟 | 列表刷新，仅显示 name 匹配 `alpha` 的项目行 |
| 4 | 观察筛选结果 | 列表中只保留匹配的项目，不匹配的行消失 |
| 5 | 清空搜索框内容（全选 → 删除） | 列表恢复显示全部项目（或再次触发防抖后恢复） |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 搜索后列表行数 | ≤ 搜索前行数（过滤子集） |
| 每行 name 字段 | 均包含输入的关键词（忽略大小写） |
| URL search 参数 | 同步包含 `?search=alpha` |

| 3 | 将鼠标悬停在活跃项目行上对比 | 活跃行显示完整的编辑 + 归档按钮 |

**最终断言**:

| 断言项 | 预期 |

### TC-E2E-M1-01-012 网络中断时的错误处理

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-01-012 |
| **用例名称** | 网络异常 — 加载列表或归档时断网，显示错误提示和重试 |
| **对应AC** | AC-M1-E04, UI-M1-02 |
| **优先级** | P1 |
| **前置条件** | 已在项目列表页；通过 Playwright 网络层模拟离线/超时 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 模拟网络离线（Playwright context.setOffline(true)） | 当前已加载数据保持显示 |
| 2 | 触发需要网络的操作（如切换状态筛选触发重新请求） | 列表区域显示 Error Boundary 或通用错误提示"网络连接失败，请检查网络后重试"；出现「重试」按钮 |
| 3 | 点击「重试」按钮 | 按钮显示 loading 态；尝试重新请求 |
| 4 | 模拟网络恢复（setOffline(false)） | 重试成功；列表恢复正常数据显示 |
| 5 | （变体）模拟归档操作时断网 | 归档确认弹窗中点击确认后，按钮停止 loading 态；弹窗内或页面显示网络错误 Toast；已填写的弹窗内容不丢失（编辑态保留） |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| 错误提示 | 用户友好的中文文案，非技术性错误码 |
| 重试按钮 | 存在且可点击 |
| 断网期间操作按钮 | 归档确认弹窗的确认按钮在超时后停止 loading（UI-M1-02） |
| 数据保留 | 断网时不丢失用户已输入的内容（如表单填写值、弹窗状态） |
