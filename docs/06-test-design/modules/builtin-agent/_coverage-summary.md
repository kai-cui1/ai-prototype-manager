## 测试特殊说明

### Mock 策略

本模块涉及 LLM / Embedding / MCP 三个外部依赖，API 测试采用以下 mock 策略：

| 依赖 | Mock 方式 | 说明 |
|------|----------|------|
| LLM Provider | 环境变量注入 mock provider | 返回固定回复（含/不含卡片 JSON） |
| Ollama Embedding | Mock HTTP 服务 | 返回固定维度向量 |
| MCP Server | Mock MCP Client | 可配置成功/失败/超时 |

### 测试数据清理

// cleanupTestData() — Agent Server 测试专用
export async function cleanupAgentTestData(): Promise<void> {
  // 删除 e2e- 前缀会话（CASCADE 清理 messages + cards + items）

}
