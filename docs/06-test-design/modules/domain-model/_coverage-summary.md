## 3. 测试数据安全核查

所有测试用例均遵循以下安全规则：

| # | 规则 | 本模块实现方式 |
|---|------|--------------|
| 1 | INSERT 数据必须带 `e2e-` 前缀 | 所有 entity.name、project.name 均以 `e2e-` 开头 |
| 2 | DELETE 必须带 WHERE 条件 + 前缀匹配 | `where(ilike(name, 'e2e-%'))` 或 `where(eq(projectId, testProjectId))` |
| 3 | testProjectId 本身以 `e2e-` 命名隔离 | 测试项目 name=`e2e-proj-dm`，确保不污染生产项目 |
| 4 | entity_relations 无 name 字段 | 用 project_id 限定，测试项目 ID 与生产数据不重叠 |
