# 画布显示配置 — UI 交互测试用例

> 功能点: **F-M2-05** | 优先级: **P1**
> 对应 PRD: `docs/03-prd-ux/modules/domain-model/domain-model-prd.md` §4.5
> 对应交互设计: `docs/03-prd-ux/modules/domain-model/domain-model-interaction.md` §3.1.5
> **验证方式**: 人工（前端行为，无后端接口）

---

## 测试范围说明

F-M2-05 为纯前端功能，所有配置持久化到 `localStorage`。本文件仅包含 UI 交互测试用例，无 API 自动化测试用例。

---

## 正常流程

### TC-UI-M2-05-001：工具栏存在"画布设置"入口

| 项 | 内容 |
|----|------|
| **前置条件** | 已进入任一项目的领域模型页面（ER 图视图） |
| **操作步骤** | 查看顶部工具栏右侧区域 |
| **预期结果** | 工具栏"新建实体"按钮右侧存在 `Settings2` 图标按钮，鼠标悬停显示 Tooltip "画布设置" |

---

### TC-UI-M2-05-002：点击"画布设置"按钮滑出配置侧边栏

| 项 | 内容 |
|----|------|
| **前置条件** | 已进入领域模型页面 |
| **操作步骤** | 点击工具栏"画布设置"图标按钮 |
| **预期结果** | 右侧滑出宽 280px 的配置侧边栏，标题为"画布设置"，包含"显示设置"分组和"展示关系名称"Switch 开关 |

---

### TC-UI-M2-05-003：配置侧边栏默认状态

| 项 | 内容 |
|----|------|
| **前置条件** | 首次进入该项目的领域模型页面（localStorage 中无该项目的配置） |
| **操作步骤** | 点击打开配置侧边栏 |
| **预期结果** | "展示关系名称"开关默认为**关闭**状态 |

---

### TC-UI-M2-05-004：开启"展示关系名称"后关系线显示常驻标签

| 项 | 内容 |
|----|------|
| **前置条件** | 已有至少一条关系；配置侧边栏已打开 |
| **操作步骤** | 将"展示关系名称"Switch 切换为**开启** |
| **预期结果** | 画布中所有关系线中部出现常驻文字标签（display_name 或 kind 中文映射），无需重新加载 |

---

### TC-UI-M2-05-005：关闭"展示关系名称"后常驻标签消失

| 项 | 内容 |
|----|------|
| **前置条件** | "展示关系名称"开关处于开启状态，画布有关系线标签 |
| **操作步骤** | 将"展示关系名称"Switch 切换为**关闭** |
| **预期结果** | 画布中所有关系线的常驻标签消失；Hover Tooltip 行为不受影响 |

---

### TC-UI-M2-05-006：配置持久化（刷新后保持）

| 项 | 内容 |
|----|------|
| **前置条件** | 已将"展示关系名称"切换为开启 |
| **操作步骤** | 刷新页面 |
| **预期结果** | 刷新后"展示关系名称"仍为**开启**状态，关系线标签继续显示 |

---

### TC-UI-M2-05-007：配置按项目隔离

| 项 | 内容 |
|----|------|
| **前置条件** | 项目 A 开启了"展示关系名称"；切换到项目 B（首次进入） |
| **操作步骤** | 在项目 B 中打开配置侧边栏 |
| **预期结果** | 项目 B 的"展示关系名称"为默认**关闭**状态，不受项目 A 配置影响 |

---

### TC-UI-M2-05-008：关系名称标签内容优先级

| 项 | 内容 |
|----|------|
| **前置条件** | 有两条关系：关系 A 有 display_name="下单"；关系 B 无 display_name，relationKind="dependency" |
| **操作步骤** | 开启"展示关系名称"开关 |
| **预期结果** | 关系 A 标签显示"下单"；关系 B 标签显示"依赖" |

## Bug 修复验收

### TC-UI-M2-FIX-001：聚合关系末端显示空心菱形

| 项 | 内容 |
|----|------|
| **前置条件** | 已创建一条 `aggregation` 类型的关系 |
| **操作步骤** | 在 ER 图画布中观察该关系线 |
| **预期结果** | 关系线的 target 端显示**空心菱形**（◇），而非实心箭头 |
| **Bug 描述** | 修复前所有关系类型均显示实心箭头（`ArrowClosed`） |

### TC-UI-M2-FIX-003：association / dependency 末端保持普通箭头

| 项 | 内容 |
|----|------|
| **前置条件** | 已创建 `association` 和 `dependency` 类型的关系各一条 |
