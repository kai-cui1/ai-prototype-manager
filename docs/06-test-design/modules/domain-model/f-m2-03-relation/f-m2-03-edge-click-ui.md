# 关系管理（关系线点击）— UI 交互测试用例

> 功能点: **F-M2-03**（扩展：关系线点击选中 + Inspector 关系详情模式）
> 优先级: **P0**（关系管理）/ **P1**（画布交互增强）
> 对应 PRD: `docs/03-prd-ux/modules/domain-model/domain-model-prd.md` §4.3（步骤5 + B-M2-F03-01）
> 对应交互设计: `docs/03-prd-ux/modules/domain-model/domain-model-interaction.md` §3.2.3 线交互
> **验证方式**: 人工（前端画布交互行为）

---

## 测试范围说明

本文件覆盖 ER 图画布中"点击关系线 → Inspector 关系详情模式"的 UI 交互测试用例。关系线的 Hover Tooltip、常驻标签等行为已在 `f-m2-05-canvas-settings/f-m2-05-ui.md` 中覆盖，此处仅关注**点击选中**及**Inspector 关系详情模式**相关交互。

---

## 正常流程

### TC-UI-M2-03-EDGE-001：关系线可点击

| 项 | 内容 |
|----|------|
| **前置条件** | 项目中已创建至少两个实体和一条关系，处于 ER 图视图 |
| **操作步骤** | 点击画布中任意一条关系线 |
| **预期结果** | 1. 该关系线视觉高亮（线宽增大 / 颜色变化）；2. 右侧 Inspector 滑出 |

---

### TC-UI-M2-03-EDGE-002：Inspector 进入关系详情模式

| 项 | 内容 |
|----|------|
| **前置条件** | 已通过 TC-UI-M2-03-EDGE-001 点击选中一条关系线 |
| **操作步骤** | 观察 Inspector 内容 |
| **预期结果** | Inspector 标题显示"关系详情"；仅显示"关系"选项卡（无"基本信息"和"字段"选项卡）；内容为当前选中的那条关系 |

---

### TC-UI-M2-03-EDGE-003：关系详情内容正确

| 项 | 内容 |
|----|------|
| **前置条件** | 已点击选中一条 `dependency` 类型关系，display_name="下单用户" |
| **操作步骤** | 查看 Inspector 中关系详情卡片 |
| **预期结果** | 卡片显示：源实体名 → 目标实体名；"依赖" Badge；基数值；display_name "下单用户"；编辑/删除按钮 |

---

### TC-UI-M2-03-EDGE-004：关系详情无 display_name 时显示 kind

| 项 | 内容 |
|----|------|

| **预期结果** | 卡片中不显示名称字段（或显示为空），关系类型 Badge 显示"聚合" |

### TC-UI-M2-03-EDGE-005：关系详情模式下可编辑关系

| 项 | 内容 |
|----|------|
| **前置条件** | 已通过点击关系线进入 Inspector 关系详情模式 |
| **操作步骤** | 点击关系详情卡片中的编辑按钮（Pencil 图标） |
| **预期结果** | 弹出 RelationDialog（编辑模式），回填当前关系的所有字段；保存后 Inspector 关系详情刷新 |

### TC-UI-M2-03-EDGE-006：关系详情模式下可删除关系

| **预期结果** | 弹出 DeleteRelationDialog 二次确认；确认后关系删除，画布中关系线消失，Inspector 收起 |

## 边界场景

### TC-UI-M2-03-EDGE-012：删除关系后 Inspector 收起

| 项 | 内容 |
|----|------|
| **前置条件** | 已选中一条关系线（Inspector 关系详情模式） |
| **操作步骤** | 在关系详情中点击删除 → 确认删除 |
| **预期结果** | 关系从数据库删除；画布中该关系线消失；Inspector 收起；其他关系线不受影响 |

---

### TC-UI-M2-03-EDGE-013：编辑关系后画布和 Inspector 同步刷新

| 项 | 内容 |
|----|------|
| **前置条件** | 已选中一条 `dependency` 关系线 |
| **操作步骤** | 在关系详情中点击编辑 → 将类型改为 `aggregation` → 保存 |
| **预期结果** | 关系线视觉更新（从灰色实线 → 蓝色虚线 + 空心菱形）；Inspector 关系详情中 Badge 更新为"聚合" |

---

### TC-UI-M2-03-EDGE-014：同时存在多条关系线时仅高亮选中的一条

| 项 | 内容 |
|----|------|
| **前置条件** | 项目中存在 3 条以上关系线 |
| **操作步骤** | 点击其中一条关系线 |
| **预期结果** | 仅点击的那条线高亮，其他关系线保持默认样式 |

---
