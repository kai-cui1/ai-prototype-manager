## 待讨论 / 待决策

### 领域模型行为建模（2026-06-01 记录）

**背景**：当前领域模型（Phase 1 M2）中 EntityDef 只有 `fields` 和 `relations`，不支持"行为"概念，因此 UML 的 `Realization` 关系类型在现阶段无法表达。

**讨论结论**：
- PM 不希望在领域模型中引入过多只有编程层面才有意义的概念
- Realization 的理解定位为：**一个抽象业务行为的具体实现**（非"接口实现"的编程概念）
  - 示例："支付"是抽象行为，"微信支付"、"支付宝支付"是它的 Realization
- 前提依赖：需要先在领域模型中引入"行为（behavior）"作为一等公民概念
- **决策：延迟到 Phase 2 再评估和实现**，Phase 1 保持现有 3 种 UML 关系类型（dependency / aggregation / composition）
