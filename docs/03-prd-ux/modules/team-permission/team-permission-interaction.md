### 1.3 路由守卫规则

| 守卫 | 条件 | 行为 |
|------|------|------|
| **AuthGuard** | 无有效 JWT | 重定向 `/login`，携带 `?redirect=` 原路径 |
| **MustChangePasswordGuard** | `mustChangePassword=true` | 重定向 `/change-password`，仅允许访问该页 + logout |
| **SuperAdminGuard** | `platformRole ≠ super_admin` | 重定向 `/`，Toast "无权限访问" |
| **TeamAccessGuard** | 非团队成员且非 SuperAdmin | 重定向 `/teams`，Toast "无权限" |

## 2. 全局交互约定

| 约定编号 | 约定内容 | 适用场景 |
|---------|---------|---------|
| UI-M6-01 | **确认弹窗**：所有破坏性操作（禁用用户/解散团队/撤销共享/撤销 Token）使用 `AlertDialog`；确认按钮 `destructive` variant | 破坏性操作 |
| UI-M6-02 | **Loading 态**：异步操作按钮在请求期间显示 spinner + 禁用，防重复提交 | 所有写操作 |
| UI-M6-03 | **Toast 反馈**：写操作成功后右上角 Toast（3s 消失）；格式："XXX 已创建" / "XXX 已撤销" | 所有写操作 |
| UI-M6-04 | **Esc 取消**：所有 Dialog/AlertDialog/Sheet 支持 Esc 关闭 | 所有弹窗 |
| UI-M6-05 | **空状态引导**：列表无数据时显示空状态插画 + 提示 + 操作按钮 | 所有列表页 |
| UI-M6-06 | **权限隐藏**：无权限的操作按钮直接不渲染（非 disabled），避免用户困惑 | 全局 |
| UI-M6-07 | **401 自动跳转**：API 返回 401 时清除本地 token，跳转 `/login?redirect=当前路径` | 全局 |
| UI-M6-08 | **403 提示**：API 返回 403 时 Toast "权限不足，无法执行此操作" | 全局 |
| UI-M6-09 | **表单重置**：Dialog 每次打开为干净状态，关闭后重置 | 所有 Dialog |
| UI-M6-10 | **防抖搜索**：搜索框 300ms 防抖 | 所有搜索框 |

```
│                    │  [                ] │                       │
│                    │                     │                       │

```

### 3.2 页面元素清单

| 区域 | 元素 | 组件 | 说明 |
|------|------|------|------|
| 居中卡片 | Logo + 标题 | `img` + `H1` | 品牌标识，居中 |
| 表单 | 邮箱输入框 | `Input` type=email | placeholder "请输入邮箱"；autofocus |
| 表单 | 密码输入框 | `Input` type=password | placeholder "请输入密码"；右侧眼睛图标切换可见性 |
| 表单 | 登录按钮 | `Button` (primary, full-width) | 文案"登录"；loading 时显示 spinner |
| 错误提示 | 错误文案 | `Alert` (destructive) | 登录失败时显示在表单上方："邮箱或密码错误" |
| 锁定提示 | 锁定文案 | `Alert` (warning) | 账号锁定时："账号已锁定，请 15 分钟后重试" |

### 3.3 交互流程

| 步骤 | 用户操作 | 系统响应 |
|------|---------|---------|
| 1 | 输入邮箱 + 密码，点击「登录」或按 Enter | 前端校验非空 → 按钮 loading → `POST /api/auth/login` |
| 2a | 登录成功 + mustChangePassword=false | 存储 token → 跳转 `redirect` 参数指定的页面（默认 `/`） |
| 2b | 登录成功 + mustChangePassword=true | 存储 token → 跳转 `/change-password` |
| 2c | 登录失败（401） | 显示错误 Alert "邮箱或密码错误"；密码框清空；按钮恢复 |
| 2d | 账号锁定（423） | 显示警告 Alert "账号已锁定，请 15 分钟后重试" |
| 3 | 修改输入后重试 | 错误 Alert 消失，重新提交 |

### 3.4 交互细节

| 场景 | 行为 |
|------|------|
| 已登录用户访问 `/login` | 自动重定向到 `/`（不显示登录页） |
| 邮箱格式不合法（失焦） | 字段下方红色提示"请输入有效的邮箱地址" |
| 密码为空点击登录 | 密码字段下方红色提示"请输入密码" |
| 网络错误 | Toast "网络连接失败，请检查网络后重试" |

### 4.1 页面布局

> 路由：`/change-password`（独立全屏页面，无 Sidebar；顶部仅有 Logo + "退出登录"链接）

```
┌─────────────────────────────────────────────────────────────────┐
│  [APM Logo]                                    [退出登录]         │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│              ┌─────────────────────────────┐                     │
│              │  首次登录，请设置新密码       │                     │
│              │                             │                     │
│              │  新密码 *                    │                     │
│              │  [                       ]  │                     │
│              │  ≥12位，含大小写+数字+符号   │                     │
│              │                             │                     │
│              │  确认新密码 *                │                     │
│              │  [                       ]  │                     │
│              │                             │                     │
│              │  密码强度: [████░░] 中等     │                     │
│              │                             │                     │
│              │  [      确认修改      ]     │                     │
│              └─────────────────────────────┘                     │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 页面元素清单

| 元素 | 组件 | 说明 |
|------|------|------|
| 标题 | `H2` | "首次登录，请设置新密码" |
| 新密码 | `Input` type=password | 右侧眼睛图标切换可见性 |
| 确认新密码 | `Input` type=password | 实时比对是否一致 |
| 密码强度指示器 | 自定义 `Progress` | 4 段：弱(红)/中(橙)/强(绿)/极强(深绿) |
| 强度规则提示 | `Text` (muted, sm) | "≥12位，含大小写字母、数字和符号" |
| 确认修改按钮 | `Button` (primary, full-width) | 全部校验通过后启用 |
| 退出登录 | `Button` (ghost, link) | 清除 token → 跳转 `/login` |

### 4.3 交互流程

| 步骤 | 用户操作 | 系统响应 |
|------|---------|---------|
| 1 | 输入新密码 | 实时计算强度，更新指示器 |
| 2 | 输入确认密码 | 实时比对，不一致时确认框下方红色提示"两次密码不一致" |
| 3 | 点击「确认修改」 | 前端校验（强度+一致性）→ `POST /api/auth/change-password` (无需 oldPassword) |
| 4a | 成功 | Toast "密码修改成功" → 跳转 `/` |
| 4b | 失败（强度不足） | 新密码字段下方红色提示具体不满足项 |

### 4.4 密码强度计算规则

| 等级 | 条件 | 颜色 |
|------|------|------|
| 弱 | 满足 < 3 项 | 红色 1/4 |
| 中 | 满足 3 项（长度+大写+小写+数字+符号 中任 3） | 橙色 2/4 |
| 强 | 满足 4 项 | 绿色 3/4 |
| 极强 | 5 项全满足 + 长度 ≥ 16 | 深绿 4/4 |

| 菜单项 | 可见条件 | 行为 |
|--------|---------|------|
| 设为 Admin | 当前用户是 Owner 且目标是 Member | 直接执行，Toast "已将 XXX 设为管理员" |
| 设为 Member | 当前用户是 Owner 且目标是 Admin | 直接执行，Toast |

> **Owner 行**：⋮ 菜单仅显示"转让 Owner"（不可移除/降级自己）
