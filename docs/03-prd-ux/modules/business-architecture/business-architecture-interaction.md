## 2. 全局交互约定

| 约定编号 | 约定内容 | 适用场景 |
|---------|---------|---------|
| UI-M4-01 | **确认弹窗**：删除架构节点使用 `AlertDialog`，确认按钮用 `destructive` 红色；普通编辑/关联操作无需二次确认 | 删除架构节点 |
| UI-M4-02 | **Loading 态**：所有写操作按钮在请求期间显示 spinner + 禁用 | POST/PUT/PATCH/DELETE |
| UI-M4-03 | **Toast 反馈**：写操作成功后弹出 Toast（右上角 3s）；格式："节点已创建" / "节点已删除" / "流程已关联" / "关联已解除" | 所有写操作 |
| UI-M4-04 | **空状态**：架构树无节点时显示空状态插画 + "还没有架构节点" + 「创建根节点」按钮 | 初始空树 |
| UI-M4-05 | **错误提示**：API 返回 409（名称重复 / 重复关联）在 input 下方或 Toast 内展示具体原因 | 创建/编辑/关联操作 |
| UI-M4-06 | **Esc 取消**：所有内联编辑态和弹窗支持 Esc 键取消，恢复原状 | 所有可编辑态 |
| UI-M4-07 | **防抖搜索**：流程搜索输入 300ms 防抖后发起请求；空关键词时不显示下拉，清空后自动收起 | F-M4-08 流程搜索框 |
| UI-M4-08 | **树形展开默认行为**：初次加载时全部根节点展开，子节点默认收起（当子节点层级≥2 时） | 架构树初始渲染 |

### 3.2 页头区域

| 元素 | 组件 | 说明 |
|------|------|------|
| 标题图标 + 标题 | `<H2>` + 图标 `h-6 w-6 text-primary` inline | 图标使用 `Layers` 或 `GitBranch`（lucide-react） |
| 副标题说明 | `text-sm text-text-secondary` | 固定文案："按业务域分类组织和导航流程" |
| 添加根节点按钮 | `Button` primary `size="sm"` | 点击触发「新建根节点」内联表单或 Dialog |

### 3.3 架构树区域

| 元素 | 说明 |
|------|------|
| 树形容器 | 自定义树组件，非 ReactFlow，使用普通 HTML + CSS 缩进渲染 |
| 节点行高 | 40px，左侧按层级缩进（每级 20px） |
| 展开/收起 | 行首 `▼` / `▶` 图标按钮；点击切换子节点显示，无子节点时不显示图标 |
| 节点显示内容 | `displayName`（主要），`name`（灰色小字附在其后，作为标识名参考） |
| 节点操作区 | 鼠标 hover 节点行时浮现（`opacity-0 group-hover:opacity-100`）：`[+ 子节点]` `[✏编辑]` `[🗑删除]` |
| 关联流程列表 | 节点展开后，其下方缩进显示关联的流程（前缀 `─`）；每条流程右侧有 `[×]` 解除关联按钮（hover 浮现） |
| 关联流程入口 | 节点展开时，流程列表末尾显示 `[+ 关联流程...]` 触发入口 |

### 3.4 架构树操作行元素清单

**节点行（展开态）：**

```
[▼] 显示名称  name  (灰色)              [+ 子节点] [✏] [🗑]
        ─ 流程 A  [active]                              [×]
        ─ 流程 B  [draft]                               [×]
        [+ 关联流程...]
```

| 元素 | 组件 | 交互 |
|------|------|------|
| 展开/收起箭头 | 图标按钮 16px | 点击切换展开态 |
| displayName | `span font-medium` | 无点击行为（Phase 1） |
| name 标识 | `span text-xs text-muted-foreground` | 不可交互 |
| 添加子节点 | `Button` ghost `size="xs"` | 见 §3.1.1 |
| 编辑按钮 | `Button` ghost `size="icon"` 铅笔图标 | 见 §3.2.1 |
| 删除按钮 | `Button` ghost `size="icon"` 垃圾桶图标（红色 hover） | 见 §3.3.1 |
| 流程条目 | `span text-sm text-text-secondary` | 无跳转 |
| 流程状态 Badge | `Badge` variant（active=`default`/draft=`secondary`/deprecated=`outline`） | 不可交互 |
| 解除关联 | `Button` ghost `size="icon"` × 图标 | 见 §4.2 |
| 关联流程入口 | `Button` ghost `size="sm"` text | 见 §4.1 |

## 4. 节点操作交互规格

### 4.1 创建架构节点（F-M4-02）

#### 4.1.1 创建根节点

**触发方式**：点击页头「+ 添加根节点」按钮

**交互方式**：在架构树顶部插入一行内联表单（Inline Form），无需弹窗

```
┌──────────────────────────────────────────────────────────────────┐
│  ┌─────────────────────────┐  ┌──────────────────────────┐       │
│  │ 显示名称（必填）          │  │ 标识名（必填）              │       │
│  │ e.g. 设备管理域           │  │ e.g. equipment-domain     │       │
│  └─────────────────────────┘  └──────────────────────────┘       │
│  ┌──────────────────────────────────────────────────────┐        │
│  │ 描述（可选）                                           │        │
│  └──────────────────────────────────────────────────────┘        │
│  [取消]   [创建]                                                   │
└──────────────────────────────────────────────────────────────────┘
```

| 字段 | 组件 | 校验 | 说明 |
|------|------|------|------|
| 显示名称 | `Input` | 必填，1-100字符 | 占位符："输入节点显示名称" |
| 标识名 | `Input` | 必填，`^[a-z0-9-]+$`，1-100字符，同项目唯一 | 占位符："小写字母/数字/连字符" |
| 描述 | `Textarea` rows=2 | 可选，最大500字符 | 占位符："节点描述（可选）" |
| 取消按钮 | `Button` ghost | — | 收起内联表单，不保存 |
| 创建按钮 | `Button` primary | 校验通过后可点击 | 提交后 Loading 态 |

**校验时机**：
- 标识名：输入后实时格式校验（非法字符立即提示）；失焦时异步唯一性校验
- 显示名称：提交时校验

**成功后**：Toast "节点已创建" + 收起内联表单 + 新节点出现在树顶部

#### 4.1.2 创建子节点

**触发方式**：鼠标 hover 节点行，点击浮现的「+ 子节点」按钮

**交互方式**：在该节点的子节点列表最后插入一行内联表单（与创建根节点表单相同，无 parentId 显示）

**成功后**：Toast "节点已创建" + 收起内联表单 + 新节点出现在父节点展开区末尾

### 4.2 编辑架构节点（F-M4-03）

#### 4.2.1 触发方式

鼠标 hover 节点行，点击浮现的「✏ 编辑」按钮（铅笔图标）

#### 4.2.2 交互方式：Popover 内嵌表单

弹出一个 `Popover`（锚点为节点行），内含编辑表单：

```
┌────────────────────────────────────────┐
│  编辑节点                      [Esc ×] │
│  ─────────────────────────────────     │
│  显示名称                              │
│  ┌──────────────────────────────────┐  │
│  │ 设备管理域                        │  │
│  └──────────────────────────────────┘  │
│  标识名                                │
│  ┌──────────────────────────────────┐  │
│  │ equipment-domain                  │  │
│  └──────────────────────────────────┘  │
│  描述                                  │
│  ┌──────────────────────────────────┐  │
│  │ ...                              │  │
│  └──────────────────────────────────┘  │
│                   [取消]  [保存]        │
└────────────────────────────────────────┘
```

| 字段 | 预填充 | 校验 |
|------|--------|------|
| 显示名称 | 当前 displayName | 必填，1-100字符 |
| 标识名 | 当前 name | 必填，格式约束，唯一性校验（排除自身） |
| 描述 | 当前 description（可空） | 可选，最大500字符 |

**成功后**：Popover 关闭 + 节点行文字就地更新 + Toast "节点已更新"

---

### 4.3 删除架构节点（F-M4-04）

#### 4.3.1 触发方式

鼠标 hover 节点行，点击浮现的「🗑 删除」按钮（垃圾桶图标）

#### 4.3.2 有子节点时（禁止删除）

直接弹出 Toast 提示（无 AlertDialog），不进入确认流程：

> **Toast 文案**（warning 样式）："请先删除或移走所有子节点，再删除此节点"

#### 4.3.3 无子节点时（允许删除）

弹出 `AlertDialog` 二次确认：

```
┌───────────────────────────────────────┐
│  确认删除节点？                         │
│                                        │
│  "设备采购管理" 将被永久删除。该节点     │
│  下的所有流程关联也将一并移除，但流程    │
│  本身不受影响。                         │
│                                        │
│  此操作不可撤销。                       │
│                           [取消] [删除] │
└───────────────────────────────────────┘
```

| 元素 | 说明 |
|------|------|
| 对话框标题 | "确认删除节点？" |
| 正文 | 包含节点 displayName（加引号）+ 影响说明 |
| 取消按钮 | `Button` ghost / outline，Esc 等同取消 |
| 删除按钮 | `Button` destructive（红色），点击后 Loading 态 |

**成功后**：AlertDialog 关闭 + 节点从树中消失 + Toast "节点已删除"

## 5. 流程关联交互规格（F-M4-05 / F-M4-06 / F-M4-07）

### 5.1 关联流程到节点（F-M4-05）

#### 5.1.1 触发方式

节点展开后，在流程列表末尾点击「+ 关联流程...」文字按钮

#### 5.1.2 搜索下拉交互

点击后，在「+ 关联流程...」位置就地展开一个搜索输入框 + 下拉结果区：

```
┌──────────────────────────────────────────────────────┐
│  ▼ 设备全生命周期管理                                   │
│    ─ 设备采购流程  [active]                       [×]  │
│    ─ 设备入库流程  [active]                       [×]  │
│    ┌─────────────────────────────────────┐            │
│    │ 🔍 搜索流程...                   [×]│            │
│    └─────────────────────────────────────┘            │
│    ┌─────────────────────────────────────┐            │
│    │  设备维修流程          [active]     │            │
│    │  设备报废处理流程       [draft]     │            │
│    │  (共 2 条结果)                      │            │
│    └─────────────────────────────────────┘            │
│    [Esc 取消]                                          │
└──────────────────────────────────────────────────────┘
```

**搜索框行为**：
- 自动获得焦点
- 实时输入 + 300ms 防抖后调用 F-M4-08 搜索接口
- 空关键词时不显示下拉列表（B-M4-20）
- Esc 或点击「取消」收起搜索框

**下拉列表行为**：
- 每条结果显示：`displayName`（主要）+ `name`（灰色小字）+ 状态 Badge
- 已关联到本节点的流程：显示灰色 `[已关联]` 标签，不可再次点击
- 点击未关联的流程条目 → 触发关联 API → Loading（该条目显示 spinner）→ 成功后收起搜索框 + Toast "流程已关联" + 流程条目出现在节点的流程列表中
- 无匹配结果时显示："未找到匹配的流程"
- 最多显示 20 条（由 API 控制）

#### 5.1.3 搜索组件 UI 元素清单

| 元素 | 组件 | 说明 |
|------|------|------|
| 搜索输入框 | `Input` size="sm" + 搜索图标（左侧）+ 清空按钮（右侧，有内容时显示） | 自动 focus，Esc 取消 |
| 结果列表 | `div` 绝对定位下拉，`shadow-md rounded-md border bg-background` | 最大高度 240px，超出滚动 |
| 结果条目 | `div` hover 变色，cursor-pointer | 点击即触发关联 |
| 流程状态 Badge | 同架构树内的 Badge 规范 | active=`default` / draft=`secondary` |
| 已关联标签 | `Badge` outline `text-muted-foreground` | 不可点击 |
| 空状态 | `div text-sm text-muted-foreground text-center py-2` | "未找到匹配的流程" |
| Loading 态 | 结果条目内 spinner | 选中条目时显示 |

### 5.2 解除流程关联（F-M4-06）

**触发方式**：hover 流程条目，点击浮现的 `[×]` 图标按钮

**交互方式**：无二次确认，直接发起 API 调用

> **设计理由**：解除关联不删除流程本身，误操作可通过重新关联恢复，无需繁琐确认。

**成功后**：流程条目从列表消失（乐观更新）+ Toast "关联已解除"

**失败后**：恢复流程条目 + Toast 错误提示

---

### 5.3 架构节点内流程排序（F-M4-07）P1

> **注意**：P1 功能，Phase 1 可暂缓实现，此处先预留交互规格。

**交互方式**：拖拽排序（节点展开态内，流程条目支持拖拽重排）

- 流程条目左侧显示拖拽手柄图标（`GripVertical`，hover 浮现）
- 拖拽过程中目标位置显示蓝色占位线
- 拖拽释放后立即更新本地顺序（乐观更新）+ 异步调用排序 API
- 排序失败时 Toast 提示 + 恢复原顺序

## 6. AI 系统交互规格（语义层设计）

### 6.1 页面语义标注

| UI 元素 | 语义角色 | 数据绑定 |
|---------|---------|---------|
| 架构树根节点行 | `ArchNode[level=root]` | `{ id, name, displayName, parentId: null }` |
| 架构树子节点行 | `ArchNode[level=child]` | `{ id, name, displayName, parentId }` |
| 节点下的流程条目 | `ProcessRef` | `{ processId, name, displayName, status, sortOrder }` |
| 关联流程搜索框 | `ProcessSearchInput` | 输入 → 调用 F-M4-08 |
| 搜索结果条目 | `ProcessSearchResult` | `{ id, name, displayName, status }` |
| 删除确认对话框 | `DestructiveConfirm[target=ArchNode]` | 绑定被删节点 `{ id, displayName }` |

### 6.2 核心交互逻辑结构

```
业务架构页面
├── 加载事件：进入页面 → GET /architectures?projectId → 组装树形 → 渲染
├── 节点展开事件：点击 ▼/▶ → 切换本地 expandedIds Set → 无 API 调用
├── 创建节点事件：提交表单 → POST /architectures → 更新本地树 → Toast
├── 编辑节点事件：Popover 保存 → PATCH /architectures/:id → 就地更新 → Toast
├── 删除节点事件：AlertDialog 确认 → DELETE /architectures/:id → 从树中移除 → Toast
├── 关联流程事件：
│   ├── 输入关键词（防抖 300ms）→ GET /processes/search?q=xxx → 渲染下拉
│   └── 选择流程 → POST /architectures/:archId/processes → 追加流程条目 → Toast
└── 解除关联事件：点击 × → DELETE /architectures/:archId/processes/:processId → 移除条目 → Toast
```

### 6.3 API 端点映射

| 操作 | Method | 路径 | 说明 |
|------|--------|------|------|
| 加载架构树 | GET | `/api/v1/projects/:projectId/architectures` | 返回扁平列表，前端组装树 |
| 创建节点 | POST | `/api/v1/projects/:projectId/architectures` | body: `{ name, displayName, description?, parentId? }` |
| 编辑节点 | PATCH | `/api/v1/projects/:projectId/architectures/:archId` | body: `{ name?, displayName?, description? }` |
| 删除节点 | DELETE | `/api/v1/projects/:projectId/architectures/:archId` | 有子节点时返回 409 |
| 关联流程 | POST | `/api/v1/projects/:projectId/architectures/:archId/processes` | body: `{ processId }` |
| 解除关联 | DELETE | `/api/v1/projects/:projectId/architectures/:archId/processes/:processId` | — |
| 流程排序 | PATCH | `/api/v1/projects/:projectId/architectures/:archId/processes/order` | body: `{ processIds: string[] }` |
| 流程搜索（M3路由） | GET | `/api/v1/projects/:projectId/processes/search?q=xxx` | F-M4-08，挂 M3 路由 |
