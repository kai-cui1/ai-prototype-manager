### 测试数据准备说明

E2E 测试通过浏览器操作 UI，前置条件中的"已有数据"指**页面上可见的数据状态**：

| 数据标识 | 页面可见状态 |
|---------|------------|
| 有公司的活跃项目 | 详情页 → 组织架构 Tab → 公司列表区域显示 ≥ 1 张公司卡片 |
| 有多公司项目 | 公司列表显示 ≥ 2 家公司（含部门数和角色数统计） |
| 归档项目的公司列表 | 归档项目详情 → 组织架构 Tab → 公司卡片可见但无新建/编辑/删除按钮 |
| 空公司列表 | 组织架构 Tab → 显示空状态占位 |

| 断言项 | 预期 |
|--------|------|
| Tab 当前选中 | 「组织架构」Tab 为高亮选中态 |
| 卡片数量 | 与 DB 中该公司数量一致 |
| 每张卡片字段 | display_name + description(可为空) + 部门数统计 + 角色数统计 均可见 |
| 操作按钮 | 每张卡片有编辑和删除按钮 |
