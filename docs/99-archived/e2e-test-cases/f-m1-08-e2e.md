### 测试数据准备说明

E2E 测试通过浏览器操作 UI，前置条件中的"已有数据"指**页面上可见的数据状态**：

| 数据标识 | 页面可见状态 |
|---------|------------|
| 角色列表已加载 | 「角色」Tab 下显示角色卡片列表，含独立角色和挂载角色 |
| 有独立角色 | 某卡片显示"独立"归属 Badge，无部门名 |
| 有挂载角色 | 某卡片显示部门名归属 Badge（如"研发部"） |
| 部门筛选器可用 | 工具栏有部门下拉选择器，含"全部"/"独立"/各部门名称选项 |

## 正常流程

### TC-E2E-M1-08-001 查看角色列表 — 卡片渲染 + 归属标记 + 统计信息

| 字段 | 内容 |
|------|------|
| **用例ID** | TC-E2E-M1-08-001 |
| **用例名称** | 角色列表渲染 — 进入「角色」Tab 后，卡片列表正确展示名称、归属 Badge、描述、操作按钮 |
| **对应AC** | §4.8.3 步骤 1~3, AC-M1-19, B-M1-56, UI 元素 #5~10 |
| **优先级** | P0 |
| **前置条件** | 已在项目详情页；切换到「角色」Tab；proj-active 下有 ≥ 1 个独立角色和 ≥ 1 个挂载角色 |

**操作步骤**:

| 步骤 | 操作 | 页面预期 |
|------|------|---------|
| 1 | 点击「角色」Tab（与"概要""组织架构"平级的一级 Tab） | Tab 切换；加载角色列表；工具栏显示「新建角色」+ 搜索框 + 部门筛选器 |
| 2 | 观察角色卡片列表 | 每张卡片包含：display_name、归属 Badge（部门名或"独立"）、description（截断）、编辑/删除按钮 |
| 3 | 观察独立角色的卡片 | 归属 Badge 显示"独立"标签（特殊样式，区别于部门名 Badge） |
| 4 | 观察挂载角色的卡片 | 归属 Badge 显示所属部门 display_name（如"研发部"） |
| 5 | 观察分页控件 | 底部有分页器，默认每页 20 条 |

**最终断言**:

| 断言项 | 预期 |
|--------|------|
| Tab 层级 | 「角色」为一级 Tab（与"概要""组织架构"平级），非组织架构的子 Tab（AC-M1-U06） |
| 归属 Badge 独立角色 | 显示"独立"标签，视觉上与部门名 Badge 可区分 |
| 归属 Badge 挂载角色 | 显示具体部门名 |
| 排序 | 按 created_at DESC 排列（B-M1-56） |
| 工具栏完整性 | 新建 + 搜索 + 部门筛选器均可见且可用 |
