根目录作为编排层，通过 pnpm-workspace.yaml 声明 packages/* 为工作区包，由 turbo.json 定义跨包任务依赖：`build` 使用 `^build` 向上游依赖拓扑排序，`dev` 将 WEB_PORT / API_PORT / MCP_PORT / DATABASE_URL 注入各子进程；`test` 依赖 build 完成，`test:e2e` 独立缓存关闭。

运行时分层：
- 前端 web_app（React+Vite）与后端 api_service（Fastify+Drizzle）并行启动，均消费 environments/*.json 经 set-env.sh 生成的 DATABASE_URL；
- mcp_server 以侧进程形式运行，把 api_service 的 REST 接口包装成 Design AI 可调用的 MCP Tools，形成「AI → MCP SSE → API」调用链；
- shared_libs（@apm/shared、@apm/validation-schemas）被 api_service 与 e2e_tests 共同引用，保证 TS 类型与 TypeBox 校验契约一致；
- docs/ 作为单一事实来源，按 01~07 编号组织从设计意图到部署的全生命周期文档，驱动各子包的 PRD/技术设计/测试用例生成。

多环境通过 environments/.active 指向 dev1/dev2/uat 之一，restart-env.sh 负责重启受影响的子服务，实现同一代码库切换运行环境。
