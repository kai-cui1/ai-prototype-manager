- 路由文件以 Fastify 插件形式导出默认 async 函数，接收 app 后通过 `app.get('/path', { schema, tags, summary }, handler)` 注册，schema 使用来自 `@apm/validation-schemas` 的 TypeBox 对象声明 querystring/params/response。
- Service 层函数采用纯函数风格，第一个参数显式注入 `Db` 实例，不依赖全局单例，便于单元测试时 mock 数据库。
- 所有表定义遵循统一模式：text 主键 + `$defaultFn(() => crypto.randomUUID())`、`createdAt/updatedAt` 时间戳、`config` JSONB 存储 UI 元数据、`onDelete: 'cascade' | 'set null'` 外键策略，并通过 IIFE `(table) => [...]` 批量声明索引与唯一约束。
- 自引用外键（departments.parentId、businessArchitectures.parentId、menus.parentId、businessProcesses.parentProcessId）统一用 `// @ts-expect-error -- self-referencing FK requires circular reference (resolved at runtime)` 抑制 TS 报错。
- 全局错误处理约定：业务异常抛出带 `statusCode` 和 `code` 的 Error，由根错误处理器统一包装为 `{ error: { code, message, requestId } }` 响应体，未捕获异常返回 500 且隐藏堆栈。
- Level 0 快照对 JSONB actions/decisions 数组统一通过 `extractActionRefs` / `extractDecisionRefs` 提取引用级属性（id/name/displayName/count），禁止直接返回原始 JSONB 或纯数字计数。
