本模块由两个并列的 npm 包组成，职责清晰分离：
- `packages/shared` (`@apm/shared`)：纯 TypeScript 类型声明包，按领域边界拆分为 `src/types/{project,domain,process,organization,architecture,menu,data-flow,application,role-behavior}.ts`，通过 `types/index.ts` 聚合再经根 `index.ts` 导出，供 api、services 等上层包消费。
- `packages/validation-schemas` (`@apm/validation-schemas`)：基于 `@sinclair/typebox` + ajv 的运行时校验包，以 `base.ts` 集中定义全局字段约束（IdSchema、NameSchema、DisplayNameSchema、VersionSchema、StatusSchema、PaginationQuery 等），每个实体对应一个 `*.schema.ts` 文件，并通过 `index.ts` barrel 暴露给 api 包的 Fastify route handler 使用；`response.ts` 定义 SuccessEnvelope/PaginatedEnvelope/DeleteResponse/ErrorResponse 等通用信封，被各实体 schema 引用。

依赖方向单向：validation-schemas 可引用 shared 中的基础 Id/Name 等语义（如 snapshot.schema.ts 从 base.ts 复用），shared 不依赖 validation-schemas。两者均通过 `package.json` 的 `exports` 指向 `src/index.ts`，构建产物仅用于类型提示，实际运行直接消费源码。
