- 所有实体校验 Schema 文件遵循 `src/<entity>.schema.ts` 单文件一实体的组织方式，并通过 `index.ts` barrel 统一导出。
- 跨实体复用的字段约束（id/name/displayName/version/status/pagination/sort/filter）集中在 `base.ts` 中定义为常量，各实体 schema 直接 import 复用，避免 PRD 规则散落多处。
- 成功响应统一使用 `response.ts` 提供的 `SuccessEnvelope<T>` / `PaginatedEnvelope<T>` 函数包裹数据体，错误响应统一走 `ErrorResponse`，保持 OpenAPI 文档一致性。
- TypeBox Schema 注释采用 JSDoc 风格并在注释中显式标注 PRD 规则编号（如 G-M1-04、B-M1-88、D-14/D-15），将业务决策与代码绑定。
- Level 0 快照返回“引用级属性”（id + name + displayName + 计数类字段），而非纯数字统计，确保 AI 能进行可操作的上下文推理。
