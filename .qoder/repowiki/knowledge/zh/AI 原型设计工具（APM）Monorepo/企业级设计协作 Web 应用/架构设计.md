本模块是前端单入口应用（src/main.tsx → App.tsx），以目录为边界将功能拆分为多个子模块：project_management、applications_and_dashboard、domain_model_editor、process_editor、organization_and_roles、external_entities，以及支撑性的 shared_ui_core。
- 跨子模块通信采用 React Context + hooks 模式：ProjectContext 提供项目级上下文，DomainModelContext / ProcessEditorContext 分别承载领域模型与流程图编辑器的全局状态；各页面通过 useProjectDetail、useProcess、useDomainModel 等 hooks 消费数据。
- API 层集中在 src/api/client.ts 与 src/lib/api-client.ts，所有子模块通过统一的客户端发起请求，避免在各组件中直接调用 fetch。
- UI 体系由 src/components/ui/（shadcn 基础组件）→ src/components/common/（通用业务组件）→ 各 domain-specific components 分层复用，共享 design-tokens 与主题切换逻辑。
- 路由与权限由 ProjectRouteGuard 在应用启动时注入，确保进入任意子模块前已激活有效项目上下文。
