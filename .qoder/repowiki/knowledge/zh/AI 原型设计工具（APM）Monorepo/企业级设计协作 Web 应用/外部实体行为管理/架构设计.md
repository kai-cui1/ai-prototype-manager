- 采用页面与逻辑分离架构，`ExternalEntitiesPage` 和 `ExternalEntityDetailPage` 负责 UI 渲染与路由参数处理。
- 核心业务逻辑封装于 `useExternalEntityBehavior` Hook，统一管理 Actions 和 Decisions 的状态、加载态及 API 交互。
- 通过 `apiClient` 与后端 RESTful 接口通信，支持基于版本号（version）的乐观锁机制以确保并发数据一致性。
- 依赖 `@/components/behavior` 下的专用表单对话框组件（`ActionFormDialog`, `DecisionFormDialog`）实现复杂的创建与编辑交互。
