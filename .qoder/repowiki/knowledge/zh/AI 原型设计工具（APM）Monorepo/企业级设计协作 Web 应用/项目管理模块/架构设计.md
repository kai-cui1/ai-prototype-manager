- **分层架构**：采用 `Pages` (路由入口) -> `Hooks` (数据逻辑/状态管理) -> `Components` (UI 表现) 的分层设计。
- **数据流**：通过自定义 Hooks (`useProjectList`, `useProjectDetail`) 封装 API 请求与状态（loading/error/data），实现视图与逻辑解耦。
- **组件复用**：提取通用业务组件如 `ProjectInfoCard` (支持只读/编辑双态)、`ArchiveConfirmDialog` (二次确认) 和 `SummaryCards` (统计概览)。
- **交互模式**：详情页采用 Tab 导航切换不同视图（概要/领域/流程/组织），其中“组织架构”采用 Master-Detail 分栏布局。
