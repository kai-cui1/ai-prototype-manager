- 自定义 React Flow 节点与边组件均使用 `React.memo` 进行包裹，以优化大规模图元渲染时的性能。
- 涉及画布坐标持久化的操作（如节点拖拽结束、领域框缩放）均采用防抖策略（500ms），并在异步保存失败时通过 `toast` 提供用户反馈。
- 实体与关系的标识符（name）遵循严格的正则校验（字母开头，仅含字母数字下划线），且在创建后不可修改，仅允许更新显示名（displayName）。
- 关系连线（RelationEdge）根据类型（关联、聚合、组合等）动态选择 SVG Marker 样式，并利用 `orient="auto"` 确保箭头方向与贝塞尔曲线末端切线对齐。
