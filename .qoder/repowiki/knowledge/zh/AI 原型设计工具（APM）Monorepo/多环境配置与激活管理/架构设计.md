本模块采用「声明式 JSON + 轻量脚本」的纯数据驱动架构：
- `dev1.json` / `dev2.json` / `uat.json` 为不可变的环境定义文件，描述 web/api/db/mcp 四个服务的端口、URL、协议等连接参数；`.active` 记录当前激活环境名（默认 dev1）。
- `set-env.sh` 是核心入口：以 source 方式执行，先定位项目根目录（通过 AGENTS.md + environments/ 双重校验），再根据参数或 `.active` 解析对应 JSON，用 python3 提取 db/web/api/mcp 字段，拼接出 `postgresql://apm_dev:apm_dev_secret@host:port/database` 形式的 `DATABASE_URL`，最后 export 到当前 shell 并回写 `.active`。
- `restart-env.sh` 是上层编排脚本：内部 `source set-env.sh` 获取环境变量后，用 `lsof -ti :$port` 清理残留进程，再在根目录并行启动 `pnpm dev`（Web+API）和 `packages/mcp`（MCP Sidecar），并通过 curl 轮询各端口健康检查。
- 依赖方向单向：脚本 → JSON 配置文件，AI 仅读 JSON 与 `.active`，禁止修改；数据库凭据硬编码在脚本中，避免泄露进 .env。
