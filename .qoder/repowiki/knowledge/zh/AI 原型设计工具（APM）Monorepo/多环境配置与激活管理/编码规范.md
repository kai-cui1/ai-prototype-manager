- 每个环境一个独立 JSON 文件（dev1.json/dev2.json/uat.json），文件名即环境名，.active 仅保存字符串名称，二者配合确定当前环境。
- JSON 结构统一包含 web/api/db/mcp 四个顶层键，每个键提供 port/url/protocol，db 额外包含 host/database，新增环境只需复制模板并改端口号。
- 所有 JSON 解析都通过内联 python3 单行命令完成，不引入外部依赖如 jq，保持脚本零安装即可运行。
- 脚本对错误路径输出带 emoji 的彩色提示（✅/❌/⚠️），并在关键步骤打印当前值（DATABASE_URL、各端口）便于调试。
