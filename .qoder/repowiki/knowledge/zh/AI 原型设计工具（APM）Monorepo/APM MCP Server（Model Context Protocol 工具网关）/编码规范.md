- 每个工具文件导出一个 `registerXxxTools(server: McpServer)` 函数，内部通过 `server.tool(name, description, schema, handler)` 注册，描述字符串面向 AI 编写，schema 使用 Zod 定义参数类型与 `.describe()` 说明。
- HTTP 请求一律走模块级 `callApi(path, { method, body })`，禁止在工具文件中直接调用 fetch；对 204 No Content 的 DELETE 等响应做特殊处理并返回 `{ success: true }`。
- 工具返回值统一采用 `{ content: [{ type: 'text', text: JSON.stringify(result, null, 2) }] }` 格式，保持 MCP 文本内容一致性。
- 错误路径通过返回 `{ _error: true, status, ...data }` 结构让上层 AI 自行判断，而非抛出异常中断 MCP 调用链。
- 可选查询参数通过 `URLSearchParams` 动态拼装到 `/api/v1/projects/:projectId/...` 路径后，避免硬编码空参问号。
