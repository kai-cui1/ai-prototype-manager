- **双包协同架构**：`@apm/shared` 负责运行时类型契约（Interfaces/Types），`@apm/validation-schemas` 负责声明式校验逻辑（TypeBox Schemas）。
- **中心化基础约束**：在 `validation-schemas/src/base.ts` 中统一定义全局命名、分页、排序等基础字段模式，供各业务模块 Schema 引用，实现 PRD 规则变更的单点维护。
- **领域驱动映射**：类型与校验模式按业务域（如 Project, Domain, Organization）垂直切分，并在 `index.ts` 通过 Barrel Export 统一暴露，保持模块边界清晰。
- **响应标准化**：通过 `response.ts` 定义统一的 SuccessEnvelope 和 PaginatedEnvelope 泛型包装器，强制 API 响应结构的一致性。
