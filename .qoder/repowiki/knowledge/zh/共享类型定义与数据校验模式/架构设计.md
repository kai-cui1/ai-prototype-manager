- 采用双包架构：`@apm/shared` 负责运行时 TypeScript 类型（Types）与工具函数，`@apm/validation-schemas` 负责基于 `@sinclair/typebox` 的 Schema 定义。
- 内部遵循“基础原子 -> 业务实体”的分层设计，例如在 `validation-schemas` 中通过 `base.ts` 统一定义 ID、命名规范等原子字段，再组合成具体的业务 Schema。
- 模块间通过统一的 Barrel Export (`index.ts`) 暴露能力，支持 ESM 模块化导入，服务于上层 API 服务的 Fastify 路由校验逻辑。
