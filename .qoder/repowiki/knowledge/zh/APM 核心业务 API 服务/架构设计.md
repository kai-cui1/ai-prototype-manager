- **分层架构**：采用经典的 Controller-Service-Repository 模式。`src/routes` 定义 HTTP 端点与 OpenAPI 契约，`src/services` 封装业务逻辑，`src/models` 通过 Drizzle ORM 映射数据库 schema。
- **入口与注册**：`src/app.ts` 作为应用入口，负责注册 CORS、Swagger/Scalar 文档插件，并按模块前缀（如 `/api/v1/projects`）组装路由。
- **数据访问**：`src/db.ts` 初始化 PostgreSQL 连接池，`drizzle/config.ts` 管理迁移配置，SQL 迁移脚本存放于 `drizzle/migrations`。
- **错误处理**：通过 `src/services/common/errors.ts` 定义统一的 `AppError` 类及工厂方法，由 Fastify 全局错误处理器拦截并返回标准化 JSON 响应。
