- 该模块由 `@apm/shared`（类型与工具）和 `@apm/validation-schemas`（校验逻辑）两个子包组成，均采用 ES Module 规范并通过 `src/index.ts` 统一导出。
- `@apm/shared` 内部按职责划分为 `types`（领域模型接口，如 Domain, Project）和 `utils`（通用分页与响应构造器），形成静态契约层。
- `@apm/validation-schemas` 依赖 `@sinclair/typebox` 和 `ajv`，采用“基础字段复用”架构：在 `base.ts` 中定义全局约束（如命名规范、分页参数），并在各业务 Schema 文件中通过组合方式构建复杂的输入/输出校验对象。
- 两个包均配置了 `tsconfig.json` 进行编译管理，且 `validation-schemas` 明确服务于 API 层的 Fastify 路由校验需求。
