- **分层架构**：模块内部划分为原子UI层（`components/ui/`，基于base-ui和cva变体）、通用业务层（`components/common/`，如DataTableContainer）、布局与行为层（`components/layout/`及`behavior/`）以及基础设施层（`contexts/`, `hooks/`, `lib/`）。
- **入口与路由**：以`App.tsx`为路由配置中心，通过`ProjectRouteGuard`实现基于`ProjectContext`的项目级路由隔离，确保未激活项目时无法访问受保护路径。
- **状态管理**：采用React Context API（`ProjectContext.tsx`）管理全局项目上下文，结合localStorage实现页面刷新后的状态持久化与自动恢复。
- **依赖方向**：上层组件（如Layout, Pages）依赖下层Hook与Context获取状态，所有网络请求统一通过`lib/api-client.ts`封装的Axios实例进行，实现了视图层与数据层的解耦。
