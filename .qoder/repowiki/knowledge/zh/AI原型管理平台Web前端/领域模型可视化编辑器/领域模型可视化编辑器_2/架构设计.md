- **核心画布层**：`ERCanvas.tsx` 作为容器，集成 `@xyflow/react`，负责节点/边的状态同步、自动布局计算（网格算法）及动态连接点（Handle）优化。
- **自定义图元层**：`EntityNode`、`DomainNode` 和 `RelationEdge` 封装了具体的视觉表现与交互逻辑（如领域框的 AABB 碰撞检测、关系线的 SVG Marker 渲染）。
- **交互控制层**：`Toolbox` 提供新建入口并处理 HTML5 Drag & Drop 坐标映射；`Inspector` 侧边栏根据选中对象（实体/关系/领域）动态切换 Tab，实现属性的即时编辑与 CRUD 操作。
- **状态管理层**：通过 `DomainModelContext` 统一管理选中态、视图模式及 API 数据流，确保画布与列表视图的数据一致性。
