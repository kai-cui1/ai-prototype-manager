- **分层架构**：采用 `Pages` (路由入口) -> `Panels/Components` (业务视图) -> `Hooks` (数据逻辑) -> `UI Components` (原子组件) 的分层结构。
- **数据流管理**：通过自定义 Hooks (`useOrganization`, `useRoleBehavior`) 封装 API 调用与本地状态，实现 CRUD 操作与列表自动刷新。
- **组件复用**：`ActionFormDialog` 和 `DecisionFormDialog` 作为通用行为编辑器，被角色详情页和外部实体详情页共享；`NodeIOEditor` 进一步抽象了参数输入/输出的编辑逻辑。
- **影响分析机制**：在编辑行为时，通过 `lib/behavior-impact.ts` 工具函数对比变更前后定义，结合流程图连线数据计算影响范围，并触发二次确认 Dialog。
