- **页面层**：包含 `OrganizationPage`（组织概览）、`RolesPage`（角色列表）和 `RoleDetailPage`（角色行为详情），通过 React Router 进行路由分发。
- **逻辑层**：采用自定义 Hooks (`useOrganization`, `useRoleBehavior`) 封装业务逻辑与 API 调用，实现数据获取、状态管理及 CRUD 操作，支持乐观锁版本控制。
- **组件层**：复用通用 UI 组件库，并实现领域专用组件如 `DepartmentTree`（部门树形展示）、`NodeIOEditor`（参数编辑器）以及各类表单对话框（`ActionFormDialog`, `DecisionFormDialog`）。
- **依赖方向**：页面组件依赖 Hooks 获取数据，Hooks 依赖 `apiClient` 与后端交互，组件间通过 Props 传递状态与回调，保持单向数据流。
