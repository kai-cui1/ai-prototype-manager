- **双层路由隔离**：`App.tsx` 定义全局层（Dashboard）与项目层（`/p/:projectId/*`），后者通过 `ProjectRouteGuard` 强制注入项目上下文。
- **上下文驱动状态**：`ProjectContext` 管理全局激活项目并持久化至 LocalStorage；`DomainModelContext` 封装复杂 ER 图建模状态，实现画布、检查器与列表视图的数据同步。
- **统一 API 通信**：所有子模块依赖 `api-client.ts` 定义的 Axios 实例，统一处理 `/api/v1` 基础路径、超时控制及错误消息提取。
- **共享 UI 契约**：各业务模块复用 `components/ui` 中的原子组件及 `components/common` 中的布局容器，确保视觉与交互一致性。
