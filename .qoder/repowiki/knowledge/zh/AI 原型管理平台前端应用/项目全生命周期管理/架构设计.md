- **分层架构**：采用 `Pages` (路由入口) -> `Hooks` (数据逻辑) -> `Components` (UI 呈现) 的垂直切片结构。
- **数据流**：通过 `useProjectList` 和 `useProjectDetail` 封装 API 调用与状态管理，实现组件间的数据解耦；复杂组织管理逻辑下沉至 `useOrganization`。
- **界面模板**：严格遵循 §7.1 列表页（Header + FilterBar + DataTable）与 §7.2 详情页（Header + InfoCard + SummaryCards + Tabs）的布局规范。
- **交互模式**：详情页支持 Tab 切换（概要/领域/流程/组织），其中“组织架构”采用 Master-Detail 分栏设计，其余模块提供占位或统计视图。
