- **分层架构**：采用 `Page` (路由入口) -> `Context` (状态中枢) -> `Hook` (数据层) -> `Components` (UI层) 的四层结构。
- **状态管理**：通过 `DomainModelContext` 统一管理视图模式、选中态（实体/关系/领域互斥）及画布配置，并利用 `useDomainModel` Hook 封装对后端 API 的调用与本地状态同步。
- **核心组件**：`DomainModelEditor` 作为布局容器，动态切换 `ERCanvas` (基于 @xyflow/react) 与 `EntityListView`；`Toolbar` 负责全局控制，`Inspector` 处理详情编辑。
- **持久化策略**：画布显示配置（如关系标签）通过 `localStorage` 按项目隔离存储，节点位置变更通过防抖机制异步同步至后端。
