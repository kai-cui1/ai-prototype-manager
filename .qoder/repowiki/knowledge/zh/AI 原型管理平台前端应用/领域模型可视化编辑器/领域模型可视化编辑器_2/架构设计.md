- **核心架构**：采用 `DomainModelContext` 作为全局状态中心，通过 `useDomainModel` Hook 封装 API 交互，实现数据层与视图层解耦。
- **视图组件**：`ERCanvas.tsx` 为画布容器，注册自定义节点（`EntityNode`, `DomainNode`）和边（`RelationEdge`），处理节点拖拽、自动布局及防抖持久化逻辑。
- **交互面板**：`Inspector.tsx` 提供右侧滑出式详情面板，根据选中对象类型（实体/关系/领域）动态切换 Tab 页签，集成 CRUD 操作表单。
- **工具箱设计**：`Toolbox.tsx` 支持点击创建与 HTML5 Drag & Drop 拖放创建，通过幽灵预览（Ghost Preview）提供视觉反馈。
- **数据流**：用户操作触发 Context 中的更新函数，同步调用后端 API 并刷新本地 ER 图数据，驱动 ReactFlow 重新渲染。
