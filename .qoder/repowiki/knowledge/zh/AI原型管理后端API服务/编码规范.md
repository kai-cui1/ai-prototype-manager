- Service 层函数采用纯函数风格，将数据库连接实例 `db` 作为第一个参数显式传入，避免依赖全局单例状态。
- 路由层统一使用 TypeBox Schema 定义请求体、查询参数及响应结构，并自动注入 OpenAPI 文档标签与描述。
- 全局错误处理通过 `AppError` 类统一承载 HTTP 状态码与业务错误码，由 `app.setErrorHandler` 拦截并返回标准化 JSON 格式。
- 分页逻辑统一使用 `parsePagination` 工具函数处理页码与 pageSize 的边界校验与默认值填充，确保列表接口行为一致。
- 数据库表定义中普遍采用 `uuid` 作为主键，并包含 `createdAt` 和 `updatedAt` 时间戳字段，部分业务表引入 `version` 字段支持乐观锁。
