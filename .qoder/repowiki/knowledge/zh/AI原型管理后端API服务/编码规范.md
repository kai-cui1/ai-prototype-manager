- 服务层函数采用纯函数风格，将数据库实例 `db` 作为第一个参数显式传入，避免依赖全局单例，便于测试与上下文隔离。
- 所有列表接口统一使用 `src/services/common/pagination.ts` 中的 `parsePagination` 和 `buildMeta` 处理分页逻辑，确保 `page`、`pageSize` 及 `meta` 响应结构的一致性。
- 业务异常统一通过 `src/services/common/errors.ts` 定义的 `AppError` 及其工厂方法（如 `notFound`, `conflict`）抛出，由全局错误处理器捕获并转换为标准 JSON 错误响应。
- 数据库 schema 定义中广泛使用 `jsonb` 字段存储非结构化或半结构化配置（如 `config`, `actions`, `decisions`），以应对频繁变动的业务元数据需求，减少 DDL 变更频率。
- 路由定义中强制使用 TypeBox Schema 对 `querystring`、`body` 和 `params` 进行声明式校验，并在 Swagger 文档中自动生成对应的输入输出规范。
