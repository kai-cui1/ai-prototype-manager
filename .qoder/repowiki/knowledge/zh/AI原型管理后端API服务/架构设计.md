- **分层架构**：采用标准的 Controller-Service-Repository 模式。`src/routes/` 定义 HTTP 端点与 OpenAPI 契约，`src/services/` 封装业务逻辑，`src/models/schema.ts` 通过 Drizzle ORM 映射数据库表结构。
- **入口与插件化**：`src/app.ts` 作为应用入口，负责注册 CORS、Swagger/Scalar 文档插件及全局错误处理中间件，并通过 `app.register` 动态挂载各业务模块路由（如 projects, domain, organization）。
- **数据访问层**：`src/db.ts` 初始化 PostgreSQL 连接池，导出 `db` 实例供 Service 层调用；`drizzle/config.ts` 配置迁移生成与执行路径。
- **共享契约**：依赖 `@apm/validation-schemas` 进行请求参数校验（TypeBox），依赖 `@apm/shared` 定义通用 TypeScript 类型，确保前后端及模块间类型安全。
