- **入口与路由**：`main.tsx` 初始化 `BrowserRouter` 和 `ProjectProvider`；`App.tsx` 定义全局层（Dashboard）与项目层（`/p/:projectId/*`）路由。
- **上下文与守卫**：`ProjectContext` 管理激活的项目 ID 并持久化至 localStorage；`ProjectRouteGuard` 确保项目层路由的安全性，未激活时重定向。
- **动态布局**：`Layout.tsx` 根据上下文状态动态切换侧边栏菜单（全局/项目），集成 `HeaderBar` 和面包屑导航。
- **组件分层**：`components/ui/` 提供基础原子组件（Button, Input 等）；`components/common/` 封装业务通用组件（DataTableContainer, FilterBar）；`components/layout/` 处理页面结构。
- **工具与 API**：`lib/api-client.ts` 封装 Axios 实例与拦截器；`lib/utils.ts` 提供样式合并 (`cn`) 与日期格式化；`hooks/` 包含防抖等逻辑复用单元。
