- **分层架构**：采用 `Pages` (路由入口) -> `Hooks` (数据逻辑/状态管理) -> `Components` (UI展示/交互) 的分层设计。
- **数据流封装**：通过 `useOrganization` 和 `useRoleBehavior` 自定义 Hooks 封装 RESTful API 调用、本地状态管理及乐观更新逻辑，实现视图与数据层的解耦。
- **组件复用**：抽象出 `DepartmentTree` 处理层级数据渲染，`NodeIOEditor` 处理通用的参数输入/输出配置，并通过 `ActionFormDialog` 和 `DecisionFormDialog` 实现行为定义的标准化表单交互。
- **模块化边界**：组织管理侧重于树形结构与实体 CRUD，角色行为侧重于 JSONB 子资源的版本控制与逻辑定义，两者通过 `projectId` 和 `roleId` 进行上下文关联。
