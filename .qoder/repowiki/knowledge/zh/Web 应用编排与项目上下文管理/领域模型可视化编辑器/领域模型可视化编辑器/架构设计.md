- **分层架构**：采用 `Page` (路由入口) -> `Provider` (状态上下文) -> `Editor` (布局容器) -> `Components` (UI 组件) 的分层结构。
- **状态管理**：通过 `DomainModelContext` 集中管理视图模式、选中态（实体/关系/领域互斥）及数据加载状态，并封装 `useDomainModel` Hook 处理 API 交互与自动刷新逻辑。
- **数据流**：`DomainModelPage` 注入 `projectId`，`DomainModelProvider` 初始化数据并透传 Context，子组件通过 `useDomainModelContext` 消费状态与操作方法。
- **持久化**：画布配置（如关系标签显示）通过 `localStorage` 按项目隔离存储，在 Context 初始化时加载。
