- 行内编辑模式：在卡片组件（如 ProjectInfoCard）中通过 isEditing 状态切换只读展示与表单输入，避免页面跳转。
- 乐观锁机制：在项目更新或状态变更（归档/恢复）时，将 version 字段作为参数传递以确保并发安全。
- 防抖搜索：在列表页使用 useDebouncedValue Hook 处理搜索输入，减少不必要的 API 请求频率。
- 统一校验逻辑：在创建和编辑场景中复用正则表达式校验项目标识符（name），并提供即时前端反馈。
- 骨架屏加载：在数据获取期间（loading 状态）统一渲染 DetailSkeleton 或 Table Skeleton 以提升用户体验。
